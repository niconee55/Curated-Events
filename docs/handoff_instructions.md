# Agent Handoff Instructions

This system has two research workflows:
- a monthly seed workflow that populates the month early
- a later calendar update workflow that revisits the month after schedules, brackets, standings, and context have evolved

Both workflows should assume another agent may run later.

## What To Do
- Leave concise, practical handoff notes when they would help a later update run.
- Use handoff notes for unresolved items such as:
  - tournament placeholders that should be revisited once pairings are official
  - table-context matches whose standings explanation may need refreshing closer to kickoff
  - releases or culture items that look plausible but still need a firmer official page
- Do not leave long internal monologues or prompt commentary.
- Keep handoff notes short, factual, and operational.

## What Not To Do
- Do not rely on handoff notes as a substitute for doing the current run well.
- Do not omit a clearly important event from the main list just because a later agent can refine it.
- Do not push official placeholder events into `Search gaps` when they belong in the main list now.
